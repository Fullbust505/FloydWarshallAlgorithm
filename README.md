# Floyd Warhsall Algorithmù

A project in Graph Theory class that required us to investigate on Floyd-Warshall's algorithm and realize several tests with it.

## Prerequisites

Throughout the project, we used different Python libraries such as Numpy, Tabulate and Colorama. If you don't already have them installed, you need to run the following commands in a terminal in order to install them.

```bash
pip install numpy
```

```bash
pip install tabulate
```

```bash
pip install colorama
```
